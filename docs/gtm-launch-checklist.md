## Pages Function

`functions/api/lead.ts` — single Cloudflare Pages Function.

- POST only (405 for anything else)
- Validates: name (1–100), email (regex), organization (optional, max 200), propertyCount (enum), interest (enum), message (optional, max 2000), consent (must be true), honeypot (must be empty)
- Forwards to LEAD_WEBHOOK_URL when set; returns 503 when not set
- Never logs PII (name, email, organization)
- Unit tests: `functions/api/lead.test.ts` (8 cases, all pass)

## Operator env vars to configure

|---|---|---|

## Remaining operator decisions

1. **Legal review** — `/privacy` and `/terms` are marked "Draft — pending legal review". An attorney should review both before the site goes to a general public audience. The current text is product-accurate but not formally reviewed.

2. **staypass.app name collision** — `https://www.staypass.app` is an unrelated company ("Staypass - AI Agent for running your Airbnb"). This is a potential trademark risk at the GTM stage. Do not link to staypass.app. Flag this for your trademark/legal counsel before broad marketing.

3. **Real prices** — No dollar amounts are shown. All commercial services show "Contact us". When you are ready to publish prices, add them to Pricing.tsx. Do not copy prices from the private stay-pass-framer repo.

4. **Apple Wallet Pass Type ID** — Wallet operations require an Apple-issued Pass Type ID certificate. This is not in the open-source core. When you have it, document the configuration in docs/wallet-setup.md and update the capability matrix claim in Home.tsx accordingly.

5. **Google Wallet issuer** — Google Wallet requires a valid issuer ID and service-account key. Same approach as above.

6. **LEAD_WEBHOOK_URL** — The contact form is inert on preview until this is set. Connect it to your CRM or a webhook before GTM launch.

7. **sitemap.xml canonical URLs** — The sitemap uses `https://staypass.dev`. If you deploy to a different domain, update `VITE_SITE_URL` and regenerate or update the sitemap.

8. **OG images font rendering** — The OG PNGs use system-ui fallback for Hanken Grotesk since resvg renders without the Google Fonts CDN. For perfect on-brand rendering, supply a local font file to the resvg call in `scripts/gen-og.mjs`.
