## Provenance and preservation

Imported all 54 files, byte-for-byte, from the maintainer-supplied Claude Design export `Four design variants stacked.zip`, dated 2026-08-27. Archive SHA-256:

`1576145ab3b07da683ace845aa426e28e396775e4f17d2952a59743bef64cc53`

The original export is kept intact in `claude-design/`. Its README names separate Brand Book v2, Brand Proposal, Banners, and UI Kit `.dc.html` design pages; those pages were **not included in this archive**. The written manual, token sheets, SVG assets, component examples, and specimen pages are included. Do not invent or reconstruct the missing pages as originals.

## Application

The community/docs and QR Studio surface in `community/` uses the canonical Sky palette, original SVG mark, Hanken Grotesk, zero-radius geometry, and provided pictograms. Its build copies assets from this source; it does not maintain another editable brand copy.

Open Stay Pass surfaces use this identity. HostCasa guest continuity and Folios evidence surfaces retain their own product identities and authorization boundaries. Existing product UI still requires a separate migration review; importing the guide is not evidence that every screen has been redesigned.

The export contains a general ban on gradients in `BRANDING.md` and specific tornasol/holo exceptions in its README. The community implementation uses the common flat Sky treatment, without these optional effects. Wallet examples in the design export are visual references, not proof of provider configuration or issuance.
