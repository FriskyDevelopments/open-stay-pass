# Open Stay Pass English Companion Video Package

**Status:** Maintainer-confirmed production brief. The existing Spanish package remains unchanged. This companion package is English-first, with Spanish subtitle tracks.

## Global definition

The English package preserves the approved Folios Compliance documentary system rather than translating it into generic SaaS advertising. It uses the same evidence-first rhythm, physical credential objects, and factual capability boundary: Proof carrier, signed resolver, Paper record, System process rail, and Signal only for a verified issued decision. The audience is English-speaking independent lodging operators, open-source builders, hospitality technologists, and implementation partners.

The package consists of a **30-second 16:9 hero**, **14-second 9:16 scan/tap cut**, and **14-second 9:16 boundary cut**. Each asset uses English narration and visible English labels. Spanish `.srt` subtitle tracks provide the equivalent Spanish version without changing the preserved original Spanish films.

## Narration plan

The narrator is an adult English-speaking documentary voice with a warm, steady, clear delivery and restrained authority. Each span is generated separately. The scripts stay below the available time budget at the normal English documentary rate.

## Production constraints

Use one static Folios documentary reference for the visual anchor and then derive the 16:9 and 9:16 first frames from it. Keep the graphite phone, paper credential card, dark-teal NDEF tag, HostCasa guide, Folios Paper record, and real repository URL physically consistent. All on-screen labels are English. No clip may depict an actual door unlock, show a lock secret, claim a live Google Wallet issuance path, or use Signal except for the issued decision.

The original Spanish package remains visible and downloadable in the press kit. The English package will be introduced as **English narration · Spanish subtitles** and marked separately, so a viewer can intentionally choose either language rather than mistaking captions for the audio language.
