# Promo Capability Matrix

This is the approved claim boundary for the Open Stay Pass press kit, campaign copy, and community drafts. It is intentionally narrower than a product roadmap.

| Capability | What may be shown or claimed | What must not be claimed |
|---|---|---|
| QR credential | A QR carrier opens the same signed, short-lived, revocable resolver | QR itself is a reusable identity, door key, or fiscal record |
| NFC credential | An NDEF tag carries the same signed URL as QR | A generic NFC tag performs Apple Wallet NFC or Google Smart Tap |
| HostCasa arrival | A resolved credential can open a bilingual guest arrival guide and grounded concierge context | HostCasa provisions physical access or a smart-lock key |
| Folios handoff / fiscal state | The same resolver can surface evidence and invoice lifecycle states, including an issued decision | Every handoff is an official fiscal invoice without the applicable issuance workflow |
| Apple Wallet | The `.pkpass` signing route is tested with configured Apple signing material and appears only when an issued credential is eligible | Every device or deployment can issue Apple Wallet passes without configuration |
| Google Wallet | The UI is explicitly configuration-gated until the service-account signing path validates | Google Wallet is live, testable, or equivalent to the Apple path today |
| Smart locks | A provider-neutral adapter boundary can represent status while keeping provision/revoke/audit server-side | QR, NFC, Wallet, or the browser directly unlocks a door |
| GitHub Star call to action | The public repository link may invite a user to star after a successful run | Existing stars, adoption, testimonials, or popularity metrics not independently verified |

## Creative review gate

The generated media may be distributed internally through `/press-kit` for review. Before any external post, a human maintainer must watch each final export, confirm that its visible content matches this matrix, approve the exact destination/copy/disclosure, and approve any cost. This is a creative approval gate, not an automated substitute for it.
