# Open Stay Pass Promotional Video Blueprint

**Author:** Manus AI  
**Approval state:** Creative package confirmed by the maintainer; publication remains gated.

## Global creative definition

The campaign is a **Folios documentary credential film** rather than a generic SaaS demo or lifestyle hotel advertisement. Its visual grammar follows a strict proof-to-decision sequence: a Proof carrier, a signed resolver, a Paper fiscal record, a Signal decision, and the public GitHub repository as a technical invitation.

| Dimension | Definition |
|---|---|
| Sub-genre | Folios Compliance documentary product cinema; evidence-first, editorial, institutional but warm |
| Rendering and line | Photoreal macro evidence objects with squared documentary interface inserts, 4 px control geometry, 8 px panels, Structure hairlines; no glossy SaaS cards |
| Color and lighting | Ink `#102526` authority field, Paper `#F2F0E9` evidence record, System `#5772C7` process rail, Proof `#37CDE0` QR/provenance accent, Signal `#C6F43D` only for verified decision |
| Detail density | Sparse objects, high material fidelity, explicit source/state/time hierarchy; clean negative space rather than decorative hotel scenes |
| Audience | Independent lodging operators, open-source builders, hospitality technologists, and implementation partners |
| Primary action | Run the demo; star or fork the repository only if the credential boundary is useful |
| Language | Spanish narration; English subtitles added in final composition |

## Recurring elements

| Identifier | Appearance | Mechanical behavior |
|---|---|---|
| `guest_phone` | Graphite phone with slim black bezel, clean screen, no manufacturer logo | Moves naturally in one hand; QR scan and NFC tap resolve the same signed URL |
| `credential_card` | Paper `#F2F0E9` evidence card with Ink `#102526` typography, Proof trace rail, Structure rules, and Signal decision mark only when issued | Remains visually consistent while its state changes; never displays a lock code |
| `nfc_tag` | Small matte Ink tag with a Proof `#37CDE0` provenance mark, kept in a flat documentary composition | Contains an NDEF URL pointing to the signed arrival link; no physical-access secret |
| `hostcasa_guide` | Calm bilingual mobile arrival guide with property name, Wi-Fi, rules, and verified status | Opens after QR scan or NFC tap; content remains operator-approved |
| `folios_record` | Paper-and-Ink fiscal detail with documentary source, state, time, and next-action hierarchy, System process rail, and Signal issued mark | Transitions from review to issued while the public link remains unchanged |
| `github_repo` | Real `FriskyDevelopments/open-stay-pass` repository page | Appears only as the final open-source invitation; no fabricated star count |

## Voice and sound

The off-screen narrator is **Lucía**, a calm adult Latin American Spanish voice with warm authority, measured pace, and no exaggerated commercial smile. Each narration span is generated separately. There is no on-screen character dialogue.

The background score is separate from the generated video clips. It is instrumental electronic-organic minimalism at **92 BPM** in **D minor**, using soft pulse, muted marimba, felt piano, low analog bass, brushed metallic texture, and a restrained lift at issuance. Embedded video audio is limited to tactile scan/tap cues, room tone, and subtle device sounds.

## Claim and publication guardrails

Every visual claim must match the live MVP. Apple Wallet may be described as a real signed-pass path; Google Wallet remains credential-gated until the service-account key passes live authorization. NFC means an NDEF signed-link carrier, not terminal-based Apple Wallet NFC or Google Smart Tap. Smart-lock access remains a provider-owned adapter. No star count, customer quote, operator adoption number, or paid-placement result may be fabricated. The exact final upload destinations, copy, disclosures, and any advertising spend require maintainer approval.
