/ 01 / PRINCIPIOS




Confianza visible,
no decorativa.
Folios convierte procesos regulados en evidencia comprensible. Cada
decisión visual debe aumentar claridad, trazabilidad o velocidad
operativa.




01       Evidencia antes que ornamento
                                   Cada superficie muestra fuente, estado o siguiente acción.




02       Calma operativa                             La densidad se organiza; nunca se disfraza.




03       Movimiento con función                      El motion explica progreso, transferencia y confirmación.




04       Marca soberana                              La F canónica permanece reconocible en todo contexto.
